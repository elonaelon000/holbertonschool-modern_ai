# Holberton School - Modern AI

Exercises and projects for the Holberton School Modern AI curriculum.

## Data analysis: Web scraping

Solutions are located in [`data_analysis/web_scraping/`](data_analysis/web_scraping/).

The web scraping exercises cover HTTP requests, static HTML parsing, JSON APIs, JSON-LD, authenticated sessions, and Selenium-based product scraping.

## Data analysis: Telco Customer Churn

Solutions for tasks 0–17 are in [`data_analysis/data_preparation_visualization/`](data_analysis/data_preparation_visualization/), with an [exercise guide](data_analysis/data_preparation_visualization/README.md) covering requirements, cleaning, exploration, statistical tests, feature engineering, encoding, scaling and stratified train/test splitting.

The source Telco CSV is not committed; follow the project README to supply it and generate the precleaned CSV before running later tasks.
