# Web Scraping

Holberton School Modern AI - Data Analysis web scraping exercises.

## Files

- `0-fetch_html.py`: fetch HTML using `requests` with headers, timeouts, and HTTP error handling.
- `1-scrape_basic.py`: extract quotes from an HTML page using BeautifulSoup.
- `2-scrape_paginated.py`: follow pagination and collect quotes from multiple pages.
- `3-scrape_via_api.py`: collect quotes from a paginated JSON API.
- `4-extract_jsonld.py`: extract quotes from JSON-LD blocks in HTML.
- `5-login_and_scrape.py`: log in using a session and scrape quotes.
- `6-products_list.py`: scrape product listings using Selenium.
- `7-product_detail.py`: extract one product's details using Selenium.
- `8-scroll_and_scrape.py`: collect unique products from an infinite-scroll page using Selenium.

## Requirements

Python 3, `requests`, `beautifulsoup4`, and `selenium`. The Selenium tasks require Chrome and a compatible ChromeDriver.
