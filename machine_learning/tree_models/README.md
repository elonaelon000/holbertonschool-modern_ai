# Tree-Based Models

This project explores decision trees and ensemble classifiers using Python
and scikit-learn.

## Topics

- Decision tree construction, training, predictions and evaluation
- Pre-pruning with grid search and cost-complexity post-pruning
- Random forests and feature importance
- AdaBoost, Gradient Boosting, XGBoost and LightGBM

## Requirements

Python 3, NumPy, scikit-learn, XGBoost and LightGBM.
